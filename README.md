# Web Fundamentals Lab Project

A bilingual (Arabic and English) website created for a university final project. This project demonstrates fundamental web development skills using only HTML, CSS, and JavaScript.

## Features

### 1. User Registration Page
- Full registration form with JavaScript validation
- Arrow-key navigation (up/down) between form fields
- "Register" button redirects to the next interface after successful validation
- "Login" button is disabled by default and becomes active only after correct input validation

### 2. Subject Selection Page
- Multiple checkbox options for subject selection
- "Select All" button that selects all checkboxes
- Users can select one or more options manually

### 3. Language Features
- All content supports Arabic and English with a language toggle button
- RTL layout for Arabic and LTR layout for English

### 4. Responsive Design
- Works well across all screen sizes
- Mobile-friendly interface

### 5. About Me Page
- Displays personal information in both Arabic and English
- Professional layout with organized sections

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (No frameworks or libraries)

## How to Use
1. Open `index.html` in a web browser
2. Fill out the registration form (all fields are required)
3. Use the language toggle button in the top-right corner to switch between English and Arabic
4. Navigate through the pages using the provided buttons
